How to save a screenshot as JPG

To save a screenshot as JPG, open it in Paint on Windows and choose File → Save as → JPEG. On Mac, open it in Preview, choose File → Export, and select JPEG. Save the result under a new name. Changing a PNG filename to end in .jpg does not convert the image.

You can keep the original PNG and create a JPEG copy for an upload form, client attachment or presentation. Before sharing, check the exported image: small interface text and annotations can look different after JPEG compression.

Choose the right starting point

JPG and JPEG refer to the same image format. An app may label the export option JPEG and create a filename ending in .jpg or .jpeg. Either extension can identify JPEG content; the important step is choosing JPEG when you save or export.

Your starting point What to do Expected result
A screenshot already saved as PNG Open it in Paint or Preview and export as JPEG A separate JPEG copy of the existing capture
A copied screenshot on the Windows clipboard Paste into Paint, then explicitly save as JPEG A file you can locate and attach
A new capture you have not taken yet Capture the required area, then use one of the routes above A saved image with a format you selected
An image in a compatible Screenshot Extension editor Choose JPEG in its download format control JPEG output from that editor, if supported by your version

You do not need to retake a screenshot just to convert it. PNG files can contain a page state or error message that is no longer visible; use that original rather than trying to recreate it.

How to save screenshot as JPG on Windows

Convert a saved image in Paint

Start with the image file on your computer. These steps explicitly select JPG format in Paint; a capture shortcut alone does not select that output for you.

  1. Open the screenshot in Paint. Find it in File Explorer, right-click it and choose Open with → Paint, or open Paint and select the file from there.
  2. Check the image. Confirm that it is the correct screenshot and contains the detail you need. Make any necessary crop or annotation changes before exporting.
  3. Open the File menu and choose Save as. Select JPEG picture, or the explicit JPEG option offered by your Paint version.
  4. Choose a filename and folder. Use a descriptive name such as checkout-error.jpg. Save a new copy so the original PNG remains available.
  5. Select the Save button. If Paint warns that some image properties cannot be preserved, consider whether the image needs transparency or other features before proceeding.
  6. Open the new output. Check the text, borders and any arrows or highlights. Locate the actual saved copy before attaching it to a message.

Microsoft’s Paint documentation confirms that Paint can save images as JPEG and supports copying and pasting images. Individual menu labels can vary with the installed version.

Save a screenshot from the clipboard

A copied screenshot is not necessarily a file you can browse to. If Print Screen or a capture app has placed the image on your clipboard, paste it into an editor and create the output deliberately.

  1. Open Paint with a new canvas.
  2. Press Ctrl + V to paste the copied screenshot.
  3. Check that the intended image appeared. If it did not, copy the screenshot again from the capture app and retry.
  4. Remove unwanted canvas area or crop distractions if needed, while keeping useful labels and context.
  5. Choose the JPEG saving option described above, enter a filename and location, and save the screenshot.

Snipping Tool can help you prepare a fresh capture. If you copy that result, the paste-and-save route still applies; do not assume that copying it created a JPEG on disk. Likewise, pasting into a chat or document lets the destination app handle the image and does not guarantee JPG format for a downloadable attachment.

Save a screenshot as JPEG on Mac

Use Preview to export an existing screenshot in JPG format without changing future capture settings.

  1. Open the screenshot in Preview. In Finder, Control-click the file and choose Open With → Preview if another app opens by default.
  2. Choose File → Export. This opens the export controls for the image.
  3. Choose JPEG in the Format drop-down menu. Select JPEG, not the separate JPEG 2000 option.
  4. Adjust quality if the control is available. Choose a setting that keeps the important text and annotations readable. There is no single percentage that works best for every screenshot.
  5. Enter a new name and choose a folder. Keep the original and save the screenshot as a separate copy.
  6. Select Save, then open the exported image and inspect it at a useful reading size.

Apple documents this route in its Preview image conversion guide, including the format, quality, name and location controls.

If you cannot see a Format menu, check that you chose Export rather than Rename or Print. Renaming only changes the name; printing follows a different output workflow. Choosing JPEG in the export dialog is what creates the converted image.

For a screenshot full of interface labels, compare the result with your original before sending it. If the text is too soft, export another copy from the original at a higher available quality setting. Do not keep recompressing the already exported JPEG while trying to improve it.

Export JPEG in a compatible Chrome editor

If your installed Screenshot Extension editor includes Add image and a JPEG download option, you can use it to convert screenshots after editing. These steps depend on the controls in your version; they do not establish that every published version has this editor.

  1. Choose Add image to open a saved PNG or JPEG, or use the capture already open in the Editor.
  2. Make any needed crop or annotation changes and apply them before export.
  3. Select JPEG in the download format control.
  4. Choose Download and locate the saved output.
  5. Open the result to check the image, annotations and background. If a long capture produces more than one file, check the relevant parts before sharing them.

Copy is a separate action. It prepares an image for pasting; it does not replace choosing JPG format for a saved download. When a form requires a file attachment, use the exported file rather than assuming a pasted image will meet its requirements.

If your installed popup offers only PNG or PDF and has no compatible editor, save the capture as PNG and convert it with Paint or Preview. There is no need to find an unsupported format control in that popup.

Check the file format and readable output

Confirm that you exported, not just renamed

A JPG file should come from a JPEG save or export action. A filename ending in .jpg is not proof by itself: a renamed PNG still contains PNG data, and some viewers will open it anyway.

Start with the explicit format choice in your editor. Use file-type information from an image application where available as an additional check. A file manager’s label may rely on the extension, so do not treat that label alone as evidence that conversion occurred. If you are unsure, return to the original and export again with JPEG selected.

The MDN image format guide lists both .jpg and .jpeg for JPEG and explains the differences between JPEG and PNG.

Decide whether JPEG suits the screenshot

What matters in your image What to consider
Small text, thin lines and UI borders PNG preserves sharp edges without JPEG’s lossy compression. Check lettering closely after conversion.
A page dominated by photographs JPEG may be a practical option, but compare the actual saved size and appearance.
Arrows, colored highlights or text notes Inspect their edges and make sure the explanation remains easy to read.
Transparent areas in the source JPEG does not preserve transparency. Check the background in the exported result.
A strict upload requirement Meet the accepted extension, maximum size and pixel-dimension limits separately.

JPG format is not a guarantee of a smaller file. The result depends on the source and export settings. Conversion also cannot restore detail missing from the screenshot.

If an upload form has a maximum size in megabytes, check the saved file’s size. If it limits width or height in pixels, check the dimensions too. Converting to JPEG does not necessarily change those dimensions.

Make the shared image useful

Suppose you are sending a designer a screenshot of a broken mobile menu, and the project form accepts JPEG attachments. Keep the original PNG, finish your crop and arrow annotation, then export the JPEG copy. Check the menu label and arrow tip in the saved image before uploading.

Use a filename such as mobile-menu-overlap.jpg and describe the expected change in the accompanying note. If unrelated page content makes the image hard to read, crop the screenshot before export while retaining enough context to show where the problem occurs.

If reducing attachment size makes an error message unreadable, try removing irrelevant image area before reducing quality further. Keep the original so each attempt starts from the best available source.

Frequently asked questions

How to save screenshot as JPG without losing the original?

Open the original and export a new copy with JPEG selected. Use a distinct filename or folder, and retain the source PNG. On Windows, choose Paint’s JPEG saving option; on Mac, use Preview → File → Export → JPEG. Avoid replacing your only original while experimenting with compression.

Are JPG and JPEG different formats?

No. .jpg and .jpeg are extensions for the same JPEG format. If a form specifically requires .jpg, use that extension for an image you have actually exported as JPEG. This differs from renaming a PNG, which does not convert its contents.

Can I save a copied screenshot directly as JPEG?

On Windows, paste the copied image into Paint with Ctrl + V, then choose JPEG when saving it. Copying or pasting alone does not guarantee a particular disk format; the save or export action creates the file you can attach.

Will converting PNG to JPG reduce quality or size?

JPEG uses lossy compression, so fine text and sharp edges can change. File size may decrease or increase depending on the source and settings. Compare the exported copy with the original, and check the actual size rather than assuming conversion meets an upload limit.
