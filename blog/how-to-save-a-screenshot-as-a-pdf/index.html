How to save a screenshot as a PDF

On Windows, open your saved screenshot in the Photos app, choose Print, select Microsoft Print to PDF, then print and save the file. On Mac, open it in Preview, choose File → Export, set Format to PDF, and select Save. Both routes let you choose a filename and location for the PDF copy.

These steps convert an existing image, such as a PNG or JPEG. They do not take a new screenshot or print the live website. Keep the original image so you can return to it if you need a different crop or another export.

Choose the right route for your screenshot

You do not need an online converter for the native Windows or Mac methods. Start with the app already available on your computer.

The result is a PDF file containing your screenshot. Conversion alone does not turn the picture into an editable document, restore missing detail or guarantee a smaller attachment.

How to save a screenshot as a PDF on Windows

Start with a saved image

Find the screenshot in File Explorer. If it is still in Snipping Tool or only on the clipboard, save it as an image file first. Use a name you can recognize, such as checkout-error.png, and note the folder.

Open the image and check that it contains the right screen state. A PDF will not recover a cropped button or a message that was missing from the screenshot.

Print from the Photos app

  1. Open the screenshot in the Photos app. If another app opens by default, right-click the file and choose Open with → Photos.
  2. Choose Print. Look for the print control or menu option in the Photos app. Its position can vary by version.
  3. Select Microsoft Print to PDF from the printer list. This creates a file rather than sending the image to a physical printer.
  4. Review the preview. Choose a suitable orientation and paper size. Check that the whole image fits; turn off a fill or crop option if it cuts off the edges.
  5. Select Print. Windows opens the Save Print Output As dialog.
  6. Choose a folder and filename, such as checkout-error.pdf, then select the Save button.
  7. Open the saved PDF file. Check its page count, all four edges of the image, and the smallest text your recipient needs to read.

Microsoft documents the Microsoft Print to PDF utility and its name-and-save flow for Windows 10 and 11 in its PDF saving instructions. The utility works through an app’s print dialog; the surrounding controls depend on the app.

If the printer is missing, use Open with → Google Chrome for the screenshot, then follow the Chrome route below. This lets you finish the conversion before troubleshooting Windows printer settings.

Save a screenshot as PDF on Mac

Export from the Preview app

Mac’s Preview app can convert an image directly, without fitting it onto a printed sheet first.

  1. Locate the saved screenshot in Finder.
  2. Open it in Preview. If necessary, Control-click the file and choose Open With → Preview.
  3. From the File menu, choose Export.
  4. Open the Format menu and select PDF.
  5. Choose a new filename and the folder where you want to save the copy.
  6. Select Save, then open the new file and check the image and text.

This follows Apple’s documented image conversion workflow in Preview. Use File → Export → Format → PDF rather than looking for an identically named shortcut in every version of macOS.

For a tall screenshot, check how the resulting page reads in your PDF viewer. Exporting the whole image preserves its usefulness only if the recipient can zoom in and find the relevant detail. A page that looks complete when fitted to the window may still be too small to read at that scale.

Use Chrome for a saved PNG or JPEG

Chrome can print an image or file as well as a web page. Open your saved screenshot first so you convert the captured image rather than a new rendering of the site.

  1. Drag the PNG or JPEG from your file manager into a new Chrome tab.
  2. Confirm that the tab displays the screenshot you intended to convert.
  3. Press Ctrl + P on Windows or Command + P on Mac.
  4. Set the destination to Save as PDF.
  5. Review the preview, including orientation, margins, image fit and page count. Available settings can vary.
  6. Select Save, choose the filename and location, and save the PDF.
  7. Reopen it to confirm that the content is complete and readable.

Google’s Chrome printing guide covers printing pages, images and files. Opening a local image this way does not require uploading it to an online conversion service.

If the print preview shows website navigation, a fresh page layout or different content, return to the saved screenshot and open that file. Printing the live site can use its print styles and produce a different result from your capture.

Export an annotated screenshot from Okea

In the current Okea editor, if your version includes Add image, you can open a saved PNG or JPEG, add explanations, and export it as PDF. Availability in the public release is not confirmed, so follow this route only if those controls are present in your installed version.

  1. Choose Add image and open the saved screenshot.
  2. Crop distracting areas if needed. Add an arrow, highlight or short text note to explain the action you want.
  3. Review the image and applied edits in the Editor.
  4. Choose PDF in the download format control, then select Download.
  5. Open the exported document and check the result before sharing it.

Adding images to an editing canvas is different from combining several screenshots as separate PDF pages. Do not assume that this workflow creates a multipage document from a batch of files.

An older popup labeled Capture as PDF captures the live page and downloads the result; it does not convert a saved screenshot. If you still need to capture the page, start with the guide to taking a full-page screenshot in Chrome.

Keep the whole image readable

The edges are cut off

First open the source image. If the missing content is already absent there, change the crop or take a new screenshot. Conversion cannot bring it back.

If the source is complete but the PDF is clipped, check the print preview for a setting that fills the page by cropping. Choose a fit option where available, or adjust the layout and scale until all four edges appear. Reopen the export to confirm the change worked.

A long screenshot becomes tiny or spans several pages

A full-page capture can be much taller than a standard sheet. Fitting it onto one page may make every label unreadable; another print layout may spread it across pages.

Check the paper size, orientation and page count before saving. Choose based on how the document will be used: a zoomable reference on screen, a printed instruction, or an attachment a colleague needs to scan quickly. For a focused discussion, make a separate crop of the relevant section and keep the full image as context. Do not shrink an entire long page just to force a one-page result.

The PDF looks blurry or the file is larger

Compare the PDF with the original at a similar reading size. If the screenshot itself is blurry, start with a better source capture. Enlarging it or changing the file format does not restore detail.

PDF file size depends on the image data and export settings; it may increase or decrease. If you need a smaller attachment, remove unnecessary image area or try another available export setting, then check image quality again. A smaller file is useful only if the necessary text remains legible.

Send a PDF that makes the next action clear

Suppose you are reporting a checkout error to a developer. Keep the original capture, then prepare a focused copy that shows the error message and the button that triggered it. Add an arrow and a note such as “This message appears after selecting Continue.” Put the reproduction steps and page URL in the ticket.

Save the PDF file with a descriptive name, such as checkout-continue-error.pdf. After attaching it, open the attachment once to check that you sent the intended version and that its notes are readable. Review visible account details before sharing. The recipient should be able to identify the issue without searching through a long, unlabeled capture.

Frequently asked questions

How to save a screenshot as a PDF without cropping it?

Start with a complete source image. In a print dialog, review the preview and use a fit setting rather than one that fills the page by cutting off edges. Check orientation and scale, then open the saved PDF to verify the result. On Mac, Preview’s File → Export → PDF route converts the image without a print-layout step.

Do I need a PDF editor?

No. Windows can create the PDF through Microsoft Print to PDF, and Mac Preview can export the image as PDF. Use an editor when you need changes such as annotations or a focused crop before sharing.

Can I turn multiple screenshots into one PDF?

Yes, with a tool that supports combining images or PDF pages. The steps above cover a single screenshot. For several files, check page order, orientation and readability in the combining tool before saving; adding images to one canvas does not necessarily create separate pages.

Will the text be searchable?

Do not assume so. A screenshot contains image data. Some tools or viewers can recognize text using OCR, but simply exporting or printing the image to PDF does not guarantee searchable or editable text. Test selection or search in the saved document if that matters to your workflow.

Why does renaming .png to .pdf fail?

Changing the filename extension does not convert the file’s contents. Use an export or print-to-PDF command to create an actual PDF, and keep the original screenshot under its original image extension.
